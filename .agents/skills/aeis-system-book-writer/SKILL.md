- Write in Polish.
- Follow the style of a system book, not a changelog.
- Distinguish clearly:

  - legacy
  - planned
- Include funding and operator mobile explicitly.
- Include model-council governance, Human Gate, memory, skills, and runtime topology.
- Keep normative statements separate from verified implementation facts.
